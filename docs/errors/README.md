# Error codes

Every diagnostic of `sf data360 retrieve`, `deploy`, `delete` and `publish` carries one of these codes. The CLI prints the code and message, then a short hint and a link to the code's page; with `--json` each diagnostic has the same `hint` and `docs` fields.

Each page explains what the code means, why the plugin stops, how to fix it, an example of the output and related codes. The hint on a page (the quoted line under its title) is the text the CLI prints.
